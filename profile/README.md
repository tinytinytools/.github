
# Tiny Tiny Tools

Free, browser-based tools for PDFs, images, text and developer work — at [tinytinytools.com](https://tinytinytools.com).

Every file tool runs entirely in your browser. Nothing you select is uploaded to a server, so there is nothing for anyone to store, scan or leak. Open the network tab while you use one and watch: zero requests carry your file.

**A few of the tools**

- [PDF Compressor](https://tinytinytools.com/pdf-compressor) — shrink a PDF to a chosen quality without sending it anywhere
- [Remove EXIF](https://tinytinytools.com/remove-exif) — strip location, device and timestamp data from photos
- [Watermark PDF](https://tinytinytools.com/watermark-pdf) — add text or image watermarks to every page
- [HEIC to JPG](https://tinytinytools.com/heic-to-jpg) — convert iPhone photos for anything that can't read HEIC
- [Regex Tester](https://tinytinytools.com/regex-tester) — live matching with group highlighting and an explanation of the pattern
- [JWT Decoder](https://tinytinytools.com/jwt-decoder) — read a token's header and payload without pasting it into someone else's site
- [CSV to JSON](https://tinytinytools.com/csv-to-json) — with header detection and type inference
- [Diff Checker](https://tinytinytools.com/diff-checker) — line-by-line comparison of two texts
- [Tola to Gram Converter](https://tinytinytools.com/tola-to-gram-converter) — gold weight in tola, aana and lal, with the jeweller's breakdown

There are also [guides](https://tinytinytools.com/guides): tests actually run, on a stated date, with the method published so you can repeat them.
